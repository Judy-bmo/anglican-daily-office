# 성무일과 (Daily Office)

「대한성공회 기도서」(2004년판)의 **아침기도·낮기도·저녁기도·밤기도**를 그날 교회력에
맞춰 보여 주는 개인 기도 도우미입니다. 웹앱(PWA)이라 브라우저로 바로 쓸 수 있고,
"홈 화면에 추가"하면 앱처럼 설치되며 인터넷 없이도 동작합니다.

```bash
npm install
npm run dev
```

## 어떻게 뽑아냈나

기도서 PDF는 텍스트를 복사하면 글자가 깨집니다. 본문 서체가 `Unidocs-Korea1`이라는
자체 CID 컬렉션으로 임베드되어 있고 ToUnicode CMap이 없어, 일반적인 추출 도구는
글리프 번호만 뱉습니다.

임베드된 CFF 폰트를 뜯어 배열을 역산한 결과, 이 컬렉션이 Adobe-Korea1과 호환된다는
것을 확인했습니다.

* CID 1–94 → ASCII (`CID = 코드포인트 − 31`)
* CID 1086–3435 → KS X 1001 완성형 한글 2,350자 (EUC-KR 배열 순서)
* 나머지 기호 14자 → 페이지를 실제로 렌더링해 눈으로 확인 (`○ ● ◎ † ‡ ¶ ✛ ✠ … ' ' " "`)

여기에 더해 두 가지를 해결해야 원문이 복원됩니다.

**띄어쓰기** — 양쪽 맞추기 조판이라 줄 끝에 공백 글자가 남지 않습니다. 그래서 줄이
어절 중간에서 끊겼는지(`살`+`려` → 살려) 경계에서 끊겼는지(`결정을`+`가르쳐`) 알 수
없습니다. 책 전체를 사전 삼아 판정합니다 — *줄 안쪽에 온전히 들어 있던* 낱말 15,271개의
빈도표와, 각 토막이 낱말의 앞부분·뒷부분으로 쓰인 정도를 견주어 정합니다
(`tools/joinwords.py`). 실제 본문에서 무작위로 8,566곳을 잘라 대조한 정확도는 **98.5%**
입니다 (`scratch/eval_join.py`).

**지시문과 등급** — 붉은 지시문은 별색(Separation) 잉크로, 축일 등급은 밑줄·붉은 글씨·
이탤릭(문자 변환행렬의 기울기)으로 구분되어 있습니다. 이 조판 정보를 그대로 읽어
지시문과 본문을, 대축일·주요축일·축일·기념일을 나눴습니다.

전체 파이프라인은 다시 돌릴 수 있습니다:

```bash
python3 -m venv .venv && .venv/bin/pip install pypdf pdfplumber fonttools pymupdf pillow
.venv/bin/python tools/build.py      # 기도서 PDF → public/data/
python3 tools/fetch_bible.py         # 공동번역성서 본문 내려받기
```

## 검증

`npm test` — 37개 검사가 모두 통과합니다.

* **부활주일** 1900–2200년 전부가 주일이며 3월 22일–4월 25일 안에 듭니다(기도서 26쪽). 알려진 27개 연도 날짜와 일치합니다.
* **가·나·다해 / 1·2해** 기도서 436쪽 「성서정과표 년도구분」 대조표 39개 연도와 **전부 일치**합니다.
* **대림 1주일** 2000–2100년이 모두 "성 안드레축일(11/30)에 가장 가까운 주일"과 같습니다.
* **절기 이름** 대한성공회가 공개하는 「전례독서」 캘린더 2,205일과 대조해, 캘린더 쪽 오기 14건과 표기 차이 3건을 빼면 100% 일치합니다. 차이는 근거와 함께 `churchCalendar.validate.test.ts`에 적어 두었습니다.
* **성서정과** 2004–2044년 **모든 날**에 정과가 매칭되고, 아침·저녁 시편이 빠짐없이 붙습니다.
* **성서 인용** 정과에 실린 인용 2,000여 개가 모두 성서 권으로 해석되고, 해당 본문 파일이 실제로 존재합니다.

## 화면

* **오늘** — 날짜·교회력·축일·연속 기도 기록, 네 기도 진입 카드, 오늘의 전례독서 요약
* **기도** — 예식 전문을 순서대로. 성경 낭독 부분은 배경으로 구분하고, 상단에 음성 낭독
  컨트롤, 하단에 완료 버튼. 구절을 누르면 즐겨찾기·이미지 카드 공유
* **달력** — 지난 날·앞날의 교회력과 독서 미리보기, 이번 달 전체 독서 목록, 인쇄·PDF
* **즐겨찾기** — 담아 둔 구절 모아보기
* **설정** — 화면 밝기(시스템/밝게/어둡게/시간대 자동), 글자 크기, 낭독 속도, 하루 완료
  기준, 성서 본문 표시, 기도 시간 알림, 오프라인 일괄 저장

낮기도와 밤기도는 기도서 구조상 날짜별 전례독서를 따르지 않습니다. 데이터에
`lectionaryLinked` 플래그로 구분해 두었고, 화면에서도 원문에 있는 선택지를 드롭다운으로
고르게 했습니다.

## 원문 오식과 판본 차이

원문을 함부로 고치지 않고, 화면에 인쇄된 표기를 그대로 보여 주면서 본문만 교정해 가져오고
그 사실을 알립니다 (`src/lib/errata.ts`).

* 기도서 498쪽 `전도 43:1-12, 27-32` → 전도서는 12장까지뿐입니다. 영어 원표의
  Ecclesiasticus(집회서)를 전도서로 옮긴 것으로 보여 **집회 43**을 보여 줍니다.
* `말라 4:1-6` → 개신교식 장 구분입니다. 공동번역 말라기는 3장까지이며 **3:19-24**에 해당합니다.
* `히브: 4:1-10`, `이;사 28:9-16` 등 잔글자는 조용히 정리합니다.
